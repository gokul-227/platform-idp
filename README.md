# Enterprise Identity Platform

A self-hosted identity and access management platform built on the complete
Ory ecosystem (Kratos, Hydra, Keto, Oathkeeper), with five real
applications sharing one centralized identity.

**All documentation lives in [`docs/`](docs/README.md).** Start there —
in particular:

- [`docs/02-getting-started/`](docs/02-getting-started/README.md) — what
  this is, prerequisites, quick start, repository map.
- [`docs/02-getting-started/demo-walkthrough.md`](docs/02-getting-started/demo-walkthrough.md) — a zero-technical-knowledge,
  click-by-click walkthrough.
- [`docs/10-reference/ai-handoff.md`](docs/10-reference/ai-handoff.md) —
  the always-current source of truth for what's verified-working right now.
